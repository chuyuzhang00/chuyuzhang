# Chuyu Zhang, PhD — Personal Website

A responsive static website built with HTML, CSS, and a small amount of JavaScript. It is designed for GitHub Pages.

## Files

- `index.html` — Homepage and Research Interests
- `about.html` — About, Education, and Hobbies
- `publications.html` — Selected Publications (TBC placeholders)
- `contact.html` — Contact form
- `assets/styles.css` — Site styling and responsive layout
- `assets/site.js` — Mobile navigation

## Before publishing

1. Replace the `YOUR_FORMSPREE_ID` placeholder in `contact.html` with your Formspree form ID.
2. Replace the homepage portrait placeholder with your own photo if desired.
3. Add your CV PDF and update the Curriculum Vitae link in `about.html`.
4. Replace the publication placeholders when you have publication details.

## Deploy with GitHub Pages

1. Create a public repository. For a user site, name it `YOUR_GITHUB_USERNAME.github.io`.
2. Upload all files and folders in this project (keep the folder structure).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

The site is static; no server or database is required. The contact form requires the Formspree setup described above.
